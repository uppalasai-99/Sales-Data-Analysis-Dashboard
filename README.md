Sales Data Analysis Dashboard

An interactive sales dashboard built using Python, Pandas, Plotly, and Streamlit.

Features

* Upload sales data using CSV files
* View total revenue, orders, quantity, and average order value
* Analyze monthly sales trends
* Visualize product and category performance
* Compare sales across regions
* Download filtered sales data

Technologies Used

* Python
* Pandas
* Plotly
* Streamlit

How to Run

Install the required packages:

pip install -r requirements.txt

Run the dashboard:

streamlit run sales_dashboard.py
